DatingApp

A modern full-stack web application built with ASP.NET Core and Angular as part of the Udemy course “Build an App with ASP.NET Core and Angular from Scratch” by Neil Cummings.

This project helped me gain hands-on experience in building scalable web applications using modern development practices and deploying them to the cloud.

Live Demo Application URL: https://da-2026-mm.azurewebsites.net￼

Features
* User Registration & Login
* JWT Authentication & Authorization
* Profile Management
* Photo Uploads
* Responsive Angular UI
* RESTful APIs using ASP.NET Core
* Entity Framework Core Integration
* Error Handling & Validation
* Cloud Deployment on Azure

Tech Stack:

Frontend
* Angular
* TypeScript
* Daisy UI and Tailwind
* Heroicons

Backend
* ASP.NET Core Web API
* Entity Framework Core
* SQL Server

Deployment
* Microsoft Azure
